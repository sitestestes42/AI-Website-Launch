# AI Website Launch — Course Sales Site

A polished, responsive, dependency-light landing page for the AI Website Launch course.

## Files
- `index.html` — complete site (HTML/CSS/JS in one file)

## Before publishing
1. Replace the two placeholder checkout links in `index.html` with the real Hotmart checkout URL.
2. Replace any final legal/business details with the real information.
3. Test the page on mobile and desktop.
4. Publish with your preferred host.

The site is intentionally self-contained so it can be uploaded directly to static hosting.
